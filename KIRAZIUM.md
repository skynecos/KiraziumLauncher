# Kirazium Launcher

Kirazium sunucusu için özelleştirilmiş Android Minecraft launcher'ı.

- Minecraft 26.1.2
- Fabric Loader 0.19.3
- Java 25 çalışma zamanı
- Sunucu: play.kirazium.com
- Düşük donanımlı telefonlar için optimize edilmiş varsayılan ayarlar
- Fabric API, Sodium, Lithium, FerriteCore, ImmediatelyFast, Entity Culling ve Sodium Extra

APK dosyası GitHub Actions tarafından `KiraziumLauncher-APK` adıyla üretilir.
